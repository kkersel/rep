# Rep

Минималистичный счётчик отжиманий на React Native / Expo для Android и iOS.

Нажмите **Начать**, поставьте телефон устойчиво перед собой у пола и отжимайтесь. Плечи, локти и кисти должны быть видны. Подсчёт начинается автоматически без калибровки и замирания. Верх определяется по выпрямленным локтям, низ — по согнутым. Повтор засчитывается при возвращении наверх. Есть голосовой счёт, пауза и локальная история.

## Запуск

```sh
npm install
npm start
```

Для разработки на телефоне: `npx expo run:android` или `npx expo run:ios` (для iOS нужны macOS/Xcode и настройка подписи). В браузере: `npm run web`; камера доступна на localhost или HTTPS.

Самостоятельный APK: `cd android && ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a` (JDK 17, Android SDK 36). Локальная release-сборка подписана development-ключом шаблона; для магазина нужен собственный ключ.

## Алгоритм версии 1.0.7

- MediaPipe Pose Landmarker в WebView обрабатывает фронтальную камеру локально. Видео не записывается и не отправляется. JS/WASM и модель загружаются с jsDelivr и Google Storage; нужен интернет.
- `src/poseObservation.ts`: углы плечо–локоть–кисть с поправкой на пропорции кадра; среднее по надёжно видимым рукам. Лицо не требуется. Обе щиколотки отображаются двумя точками и должны попадать в кадр.
- Обе стопы нужны только в верхней точке перед повтором. В нижней точке они могут полностью пропасть за телом или одеждой. Помимо цикла локтей, плечи должны опуститься минимум на 4% высоты кадра, поэтому простое сгибание рук на месте не засчитывается. Строгой оценки геометрии корпуса нет.
- `src/counter.ts`: выпрямление (≥155°) → сгибание (≤120°) → выпрямление. Сглаживание, подтверждение несколькими кадрами и защита от дублей. Нет зависимости от высоты плеч в первом кадре.
- Краткий пропуск наблюдений до 300 мс допустим; длительная потеря рук сбрасывает незавершённый повтор. Новый цикл можно начать на любой высоте в кадре.
- Камера занимает фоновый слой экрана и показывает полный кадр без CSS-обрезки. Минимальный зум запрашивается, если камера предоставляет его настройку. Тёмные поля сохраняют полный обзор.
- Рамка — ориентир размещения. Прежняя горизонтальная линия высоты удалена, поскольку она не соответствовала реальному положению рук.
- История сохраняется после «Сохранить» в AsyncStorage. Обновление APK поверх установленного приложения сохраняет историю.

Это счётчик видимого сгибания рук, а не оценка техники всего тела. Ракурс, перекрытые руки, одежда и освещение влияют на точность. Проверка на последовательных кадрах реального видео всё ещё нужна: два снимка подтверждают различимость поз, но не частоту и качество распознавания на всей тренировке.

## Проверка

```sh
npm run typecheck
npm test
npx expo export --platform web --platform ios
```

18 тестов, включая вручную перенесённые центры зелёных суставов с двух пользовательских скриншотов. Они дают примерно 176° в верхней точке и 81° в нижней. Проверены полный цикл, неверная начальная высота, потеря кадра, плавное движение без остановок, неподвижные позы, колебания головы и коррекция пропорций изображения. Скриншоты не включены в проект.
